Scope / Install

Install Scope on Ubuntu

One apt command installs Scope from the official .deb. This page also covers building from source and removing Scope.

Install the .deb

Scope targets Ubuntu on x86-64. Download the package for the current release, then install it from the folder that holds the file.

  1. Download scope_0.3.4_amd64.deb from the v0.3.4 release.
  2. Open a terminal in the download folder and run:
$ sudo apt install ./scope_0.3.4_amd64.deb

Start Scope from the application menu or run scope in a terminal. Scope scans your package sources when it opens.

The ./ in the command matters. Without it, apt looks for a package in its repositories, not in your download folder.

Updates to Scope

Scope checks GitHub Releases on startup. Official .deb builds from v0.3.4 can install later updates after they verify a signed SHA-256 manifest. The manifest is signed with minisign, and the public key is compiled into the app.

If you are upgrading from a build that predates the embedded verification key, install v0.3.4 by hand with the command above. Other install types open the Releases page when no verified package is available.

Build from source

Build from source on any Linux distribution where you can install Rust and the GPUI dependencies. Scope needs Rust stable. The first build takes a while because it compiles the GPUI toolkit.

Install the system libraries for the build, clone the repository, and run the app:

$ sudo apt install build-essential pkg-config libfontconfig1-dev libx11-dev libx11-xcb-dev \ libxcb1-dev libxkbcommon-dev libxkbcommon-x11-dev libwayland-dev wayland-protocols $ git clone https://github.com/khurrambhutto/scope.git $ cd scope $ cargo run

libxkbcommon-x11-dev is required even on Wayland-only sessions, because GPUI links against -lxkbcommon-x11 on Linux.

Before you open a pull request, run the same checks the project uses:

$ cargo check $ cargo test $ cargo clippy

Remove Scope

Scope installs as the scope package. To remove it, run:

$ sudo apt remove scope

Removing Scope does not remove the apps it lists. Those stay installed under their own package managers.

Other distributions

Packages for Fedora, Arch, and other .rpm-based systems are not available yet. On those systems, build from source. The .rpm release is on the roadmap, and the README lists the remaining work.
