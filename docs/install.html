Install Scope for Linux on Ubuntu

One apt command installs Scope for Linux from the official .deb. This page also covers the AppImage, installing apps with Scope, building from source and removing Scope.

Install the .deb

Scope targets Ubuntu on x86-64. Download scope_0.3.8_amd64.deb from the v0.3.8 release, open a terminal in the download folder and run:

$ sudo apt install ./scope_0.3.8_amd64.deb

Start Scope from the application menu or run scope in a terminal. Scope scans your sources when it opens.

The ./ in the command matters. Without it, apt looks for a package in its repositories, not in your download folder.

Run the AppImage

For a portable x86-64 build, download Scope-0.3.8-x86_64.AppImage, make it executable, and launch it:

$ chmod +x Scope-0.3.8-x86_64.AppImage$ ./Scope-0.3.8-x86_64.AppImage

Most AppImages, this one included, need libfuse2t64 to run. Install it with sudo apt install libfuse2t64 if the AppImage does not start.

Install apps with Scope

To install a downloaded .deb or AppImage, right-click it and choose Open With → Scope. Scope shows an installation preview before anything runs.

AppImages are added to your app menu and stored in ~/AppImages, the same folder Gear Lever uses. AppImage integration needs squashfs-tools.

Updates to Scope

Scope checks GitHub Releases on startup. Official .deb builds install later updates after they verify a SHA-256 manifest signed with minisign. The public key is compiled into the app, and Scope asks before it installs.

If you are upgrading from a build that predates the embedded verification key, install v0.3.8 by hand with the command above. Other install types open the Releases page when an update is available.

Build from source

Build from source on any Linux distribution where you can install Rust stable and the GPUI dependencies. The first build takes a while because it compiles the GPUI toolkit.

$ sudo apt install build-essential pkg-config libfontconfig1-dev libx11-dev libx11-xcb-dev \ libxcb1-dev libxkbcommon-dev libxkbcommon-x11-dev libwayland-dev wayland-protocols$ git clone https://github.com/khurrambhutto/scope.git$ cd scope$ cargo run

libxkbcommon-x11-dev is required even on Wayland-only sessions, because GPUI links against -lxkbcommon-x11 on Linux.

Before you open a pull request, run the same checks the project uses:

$ cargo check$ cargo test$ cargo clippy

Remove Scope

Scope installs as the scope package. To remove it, run:

$ sudo apt remove scope

Removing Scope does not remove the apps it lists. Those stay installed under their own package managers.

Other distributions

Packages for Fedora, Arch and other .rpm-based systems are not available yet. On those systems, run the AppImage or build from source.
