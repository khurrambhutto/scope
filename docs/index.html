How a change works

Nothing runs the moment you click

  1. 01

    Plan

    Scope builds the exact commands for the app you chose. APT changes are simulated first.

  2. 02

    Confirm

    You read the plan and confirm or cancel. A plan runs once and expires after five minutes.

  3. 03

    Revalidate

    Right before running, Scope checks the app is still installed and the deny-list still allows it.

  4. 04

    Run

    Admin commands go through the system's Polkit dialog. Progress shows at the bottom, and you can keep browsing.

Safety

Built for the machine you depend on

Package changes are hard to undo, so Scope is conservative by default. When it can't verify something, it stops.

Read how safety works

  • Never sees your password

    Admin commands go through pkexec and the system's own Polkit dialog.

  • System packages are off limits

    A deny-list blocks kernels, critical APT packages and Snap runtimes, at preview and again before running.

  • APT is simulated twice

    If the transaction would take a protected package with it, or changes after the preview, the plan doesn't run.

  • No shell in between

    Every command is a fixed argument list, so nothing typed in the app can become shell syntax.

  • Files go to the Trash

    When Scope removes files itself, such as a managed AppImage, they go to the Trash, not straight to deletion.

  • Signed self-updates

    Scope installs its own updates only after verifying a minisign-signed SHA-256 manifest, and asks first.

FAQ

Questions

Short answers. The safety page covers the checks in detail.

What is Scope for Linux?

A free, open-source app manager. It puts the apps, command-line tools and games on your machine in one searchable list, so you can see, update and uninstall them from one place after reading exactly what will run.

Which apps and tools can Scope manage?

Scope updates and uninstalls APT, Snap and Flatpak apps, user tools from uv, pipx, Cargo, npm and Bun, and AppImages in ~/AppImages installed by Scope or Gear Lever. Other AppImages and unmanaged launchers are listed for discovery. Steam games and JetBrains Toolbox IDEs are read-only and open in their own manager.

Does Scope ask for my password?

No. Commands that need root use the standard Polkit dialog through pkexec. Scope never sees or stores your password. Tools in your home directory are managed as your user, without root.

Can Scope remove critical system packages by accident?

A backend deny-list protects critical APT packages, Ubuntu desktop metapackages, kernel images, Snap runtimes and related system libraries. The check runs when Scope builds a plan and again right before it runs, and APT transactions that would take a protected package with them are rejected.

What does uninstall remove?

The app and what its package manager installed. APT uninstall purges the package's configuration but leaves settings and data in your home directory, and Scope never runs autoremove. Snap may keep a recovery snapshot. Managed AppImages and their launchers go to the Trash.

Which Linux distributions does Scope support?

Ubuntu on x86-64 is the primary target, with a .deb and an AppImage. Other distributions can run the AppImage or build from source with Rust. .rpm packages, and Fedora and Arch package-manager support, are not available yet.

How do I install Scope for Linux?

Download scope_0.3.9_amd64.deb from GitHub Releases, then run sudo apt install ./scope_0.3.9_amd64.deb. Official .deb builds update themselves after verifying a signed checksum manifest.

Is Scope free and open source?

Yes. Scope is released under the MIT License, and the source is on GitHub.
