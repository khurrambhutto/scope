What Scope is

Scope is a free, open-source Linux app manager. It shows the apps installed through APT, Snap, Flatpak, and AppImage in one searchable list. You can update or uninstall supported apps, and every change starts with a plan that lists the exact commands. Scope runs those commands only after you confirm.

Most Linux users install software from several places at once. A package from the Ubuntu archive, a Snap from the store, a Flatpak from Flathub, and an AppImage from a download folder can each carry an app the user has forgotten about. Scope reads all four sources and shows them side by side, so you can see what is installed without opening four tools.

Scope is written in Rust with Zed's GPUI toolkit. It has no webview and no embedded browser. Ubuntu is the first target.

Every change goes through a plan

Scope does not run an update or uninstall the moment you click. Each action passes four steps, and the last two protect you from changes that have shifted since you reviewed the plan.

  1. Plan

    Scope builds a preview with the exact commands for the selected app, such as apt remove -y cap. Nothing runs yet.

  2. Confirm

    You read the plan and choose Run plan, or you cancel. Each plan works once and expires after five minutes.

  3. Revalidate

    Right before running, Scope checks that the package is still installed, that an update's version has not changed, and that the deny-list still allows the action. If it cannot confirm the state, it stops.

  4. Run

    Scope runs the command through the system dialog for admin rights and streams the log into the footer. Only one package operation can run at a time.

What Scope can change, source by source

Each action runs the package manager's own command. Scope never edits the dpkg or apt databases directly.

Source What Scope lists Uninstall Update
APT Manual installs only, so dependencies stay out of the list apt remove -y apt install -y
Snap Apps and tools, with runtimes and bases hidden snap remove snap refresh
Flatpak User and system installs, each kept in its own scope flatpak uninstall -y flatpak update -y
AppImage Valid AppImages in common locations Listed only. Uninstall and update are not supported yet.
Desktop launchers Launchers that no package manager owns Listed only. Actions are disabled.

How Scope differs from other tools

Synaptic manages APT packages only. GNOME Software and KDE Discover are app stores. They show what you can install from their own catalogs, and they report on the packages they manage. Scope starts from what is already on your machine, across APT, Snap, Flatpak, and AppImage, and treats the plan as the thing you approve.

Scope does less than a full package manager on purpose. It does not install new software, clean the system, or analyze disk use. Those features are planned, but they wait until updates are complete and tested.

What works today

Scope is early. This list matches the current release, and the README tracks the same status.

Working

  • One list across APT, Snap, Flatpak, AppImage, and unmanaged desktop launchers
  • Display names, categories, and icons from desktop entries and the icon theme
  • Uninstall with a preview, Polkit authentication, and a deny-list
  • Update with a preview for APT, Snap, and Flatpak
  • Self-updater that checks a signed SHA-256 manifest for official .deb builds

Not yet

  • AppImage uninstall and update
  • .rpm release packages
  • Snap target version in the update preview
  • Whole-system cleanup and disk usage views
  • Fedora and Arch package-manager support

Install in one command

Questions

Short answers. The safety page explains the checks in detail.

What is Scope?

Scope is a free, open-source Linux app manager. It lists apps from APT, Snap, Flatpak, and AppImage in one searchable list, so you can see, update, and uninstall them from one place.

Which Linux apps can Scope manage?

Scope shows APT manual installs, Snap apps, Flatpak apps (user and system scope), AppImages, and desktop launchers that no package manager owns. Update and uninstall work for APT, Snap, and Flatpak. AppImages and desktop launchers are listed for discovery, and their actions are disabled.

Does Scope ask for my password?

No. Commands that need root use the standard Polkit dialog through pkexec. Scope never sees or stores your password.

Can Scope remove critical system packages by accident?

No. A backend deny-list protects critical APT packages, kernel images, Snap runtimes, and related system libraries. The check runs when you build a plan and again before it runs. Protected rows have a disabled uninstall action.

Which Linux distributions does Scope support?

Ubuntu is the primary target, with a .deb package for x86-64. Other Debian-based systems can build from source with Rust. .rpm packages, and Fedora and Arch package-manager support, are not available yet.

Is Scope free and open source?

Yes. Scope is released under the MIT License, and the source is on GitHub.
