Why Scope

One app manager for every Linux package source

Stop switching between apt, snap, flatpak, and file managers to find out what is installed. Scope shows it all in one place, and never changes anything without your confirmation.

One list for every source

APT, Snap, Flatpak, and AppImage apps appear together. Filter by source, or search by app or package name.

Preview before every change

Scope builds a plan that lists the exact commands. Nothing runs until you confirm the plan.

No password handling

Admin actions use the standard Polkit dialog through pkexec. Scope never sees or stores your password.

Updates in one place

Switch to Updates to see what is available. Update APT, Snap, and Flatpak apps after reviewing the preview.

System packages protected

A deny-list blocks critical packages, kernel images, and Snap runtimes. The check runs again right before apply.

Native, no webview

Written in Rust on Zed's GPUI. No Electron and no embedded browser, so it stays light and fast.

How it works

Scan, preview, apply

The same safe flow for every update and uninstall.

01 / SCAN

Read every source

Scope reads APT manual installs, Snap apps, Flatpak apps for user and system scope, AppImages, and desktop launchers.

02 / PREVIEW

See the exact plan

Pick an app, choose update or uninstall, and review the commands and the APT simulation before anything runs.

03 / APPLY

Verified, then run

Scope revalidates the package against the live system, runs the command, and streams the log to the footer.

What Scope can change, source by source

Every action uses the package manager's own command. Scope never edits dpkg or apt databases directly.

Source Uninstall Update
APT apt remove apt install (upgrade)
Snap snap remove snap refresh
Flatpak (user and system) flatpak uninstall flatpak update
AppImage Listed for discovery. Uninstall and update are not supported yet.
Desktop launchers Listed for discovery. Actions are disabled.

FAQ

Frequently asked questions

What is Scope?

Scope is a free, open-source Linux app manager. It lists apps from APT, Snap, Flatpak, and AppImage in one searchable list, so you can see, update, and uninstall them from one place.

Which Linux apps can Scope manage?

Scope shows APT manual installs, Snap apps, Flatpak apps (user and system scope), AppImages, and user-local desktop launchers. Update and uninstall are available for APT, Snap, and Flatpak. AppImages and desktop launchers are listed for discovery, and their actions are disabled.

Does Scope ask for my password?

No. Commands that need root use the standard Polkit system dialog through pkexec. Scope never sees or stores your password.

Does Scope show what will change before it runs?

Yes. Every update or uninstall builds a preview with the exact commands. Scope revalidates the package against the live system before it runs anything, and APT actions are simulated first.

Can Scope uninstall system packages by accident?

No. A backend deny-list protects critical APT packages, kernel images, Snap runtimes, and related system libraries. The check runs at preview and again before apply, and protected rows have a disabled uninstall action.

Which Linux distributions does Scope support?

Ubuntu is the primary target, with a .deb package for x86-64. Other Debian-based systems can build from source with Rust. .rpm packages, and Fedora and Arch package-manager support, are not available yet.

How do I install Scope?

Download scope_0.3.4_amd64.deb from GitHub Releases, then run sudo apt install ./scope_0.3.4_amd64.deb. To build from source, install Rust and the Linux dependencies listed in the README, then run cargo run.

Is Scope free and open source?

Yes. Scope is free and released under the MIT License. The source code is on GitHub.
