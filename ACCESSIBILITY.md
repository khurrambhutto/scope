# Accessibility

Scope aims to be usable by everyone, including people who rely on assistive technology, keyboard-only navigation, or high-contrast displays.

## Current state

Scope is an early-stage Linux desktop app built with GPUI. Accessibility support is still being built out, so some controls may not yet be fully reachable or announced by screen readers. We treat accessibility problems as bugs.

## Known limitations

- Screen reader support has not been tested.
- Not every control has a keyboard shortcut yet.
- The interface uses a fixed dark theme; there is no high-contrast or light option yet.

## Reporting a problem

Open a bug report using the issue template and describe the control, the assistive technology or input method you used, and what went wrong. Accessibility issues can also be reported privately through the contact in [SECURITY.md](SECURITY.md) if you prefer.
